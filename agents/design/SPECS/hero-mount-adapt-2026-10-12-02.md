## ۳. قلاب reduced-motion (قانون تازهٔ این نوبت)

آیتم `animations/blur-text` خودش reduced-motion ندارد. قاعدهٔ `globals.css` از روی سلکتور `.blur-text span` کار می‌کند؛ پس هندآف باید صریحاً بنویسد:

```tsx
<BlurText text="همسفر بلد در تایلند" className="blur-text" />
```

بدون `className="blur-text"`، قاعدهٔ کاهش‌حرکت CSS مرده است. برای fadeها هم کلاس `hero-fade` با قاعدهٔ سراسری:

```css
@media (prefers-reduced-motion: reduce) {
  .hero-fade { animation: none; opacity: 1; transform: none; }
}
```

قانون: «قلاب کلاسی قاعدهٔ کاهش‌حرکت». هر انیمیشنی که قاعدهٔ سراسری reduced-motion دارد، باید در هندآف نام کلاس قلابش صریح ذکر شود؛ وگرنه قاعده اعمال نمی‌شود. ثبت‌شده در KNOWLEDGE.md.

**یافتهٔ ممیزی vibefarsi (اجرای :۰۵؛ لازم‌الاجرا در mount):** قاعدهٔ موجود در `site/app/globals.css` (سلکتور `.blur-text span`) مرده است چون اسپن‌های درونی آیتم انیمیشنشان را با `style` اینلاین می‌گیرند (`components/animations/blur-text.tsx`) و استایل اینلاین هر قاعدهٔ استایل‌شیتی بدون `!important` را شکست می‌دهد. راه‌حل (diff صفر آیتم، فقط فایل پروژه):

```css
@media (prefers-reduced-motion: reduce) {
  .blur-text span { animation: none !important; opacity: 1 !important; filter: none !important; transform: none !important; }
}
```

تلهٔ مشابه برای `hero-fade`: پیاده‌سازی fade باید **فقط کلاس‌محور** باشد (تأخیرها با کلاس یوتیلیتی یا قاعدهٔ سراسری)، نه `style` اینلاین؛ وگرنه همان مرگ تکرار می‌شود.

### یافته‌های نیازمند اقدام

**یافتهٔ ۱ (اصلاح سند، برای dev در mount): روتیتر برند.** جدول §۱ می‌گوید `components/badge` با `variant="brand"`؛ سورس واقعی آیتم: `brand: "text-brand"` یعنی **متن کهربایی تنها، بدون هیچ پس‌زمینه‌ای** (توضیح خود آیتم: «برچسب وضعیت با متن رنگی، بدون پس‌زمینه و آیکون»). روی زمینهٔ روشن graphite-soft این دقیقاً نقض قانون مصرف برند است که خود چک‌لیست §۴ هم تکرارش کرده («نه کهرباییِ متن تنها روی روشن»). اصلاح §۱ (بدون تغییر آیتم):

```tsx
<Badge variant="brand" className="bg-brand/15 text-brand-foreground">تور تایلند، پرواز مستقیم از تهران</Badge>
```

`cn` کلاس `className` را بعد از واریانت می‌نشاند؛ `text-brand-foreground` بر `text-brand` غلبه می‌کند. این همان الگوی مصوب «پل برند» است (در graphite-soft، brand-foreground تیره است و کنتراست سالم است؛ رجوع به قانون «نقد فقط با تطبیق توکن واقعی» در KNOWLEDGE.md).

**یافتهٔ ۲ (ثبت انحراف در `agents/vibefarsi/DEVIATIONS.md`): دکمهٔ اولیه.** §۱ می‌گوید `variant="brand"`؛ سورس واقعی `blocks/hero`: دکمهٔ اولیه هیچ واریانت prop نمی‌گیرد و پیش‌فرض `default` (= `bg-primary`) است؛ props آیتم فقط `{label, href}` است. پس brand شدن دکمه «تطبیق فقط محتوا و توکن» نیست؛ دست‌کاری کد آیتم است. اقدام: یا قبول پیش‌فرض آیتم، یا یک خط انحراف آگاهانه (فیل برند مجاز است؛ قانون برند فقط «متن تنها روی روشن» را منع می‌کند، نه فیل کامل). توصیه: ثبت انحراف، یک خط.

### تأییدشده‌ها (بسته، بدون اقدام)

- `animations/blur-text`: پیش‌فرض `delay = 120` ✓؛ `blur-in 0.9s` ✓ (۴ کلمه: شروع آخرین ۳۶۰ms + ۹۰۰ms ≈ ۱٫۳ ثانیه؛ «≈۱٫۴» سند گرد کردن است)؛ اسپن‌ها انیمیشن را با `style` اینلاین می‌گیرند ✓ (پس قاعدهٔ reduced-motion حتماً `!important` می‌خواهد؛ قید ۱۰ §۶ سالم است).
- تیتر `text-4xl sm:text-5xl` دقیقاً آیتم ✓؛ ۴ کلمه (≤ ۶) ✓؛ `ArrowLeft` برای جلو در RTL ✓ (داکس: directional icons flip).

- slugها با پیشوند namespace ✓؛ بدون هگز/oklch خام ✓؛ بدون U+2014 ✓؛ ارقام فارسی در متن ✓؛ `tel:` با ارقام لاتین ✓ (RFC 3966).
