## ۱. هدف و جای قرارگیری

یک بنر تبلیغاتی برای یک «تور تازه»، نسخهٔ اجرایی برای **بالای صفحهٔ `/tours`** (بین هدر و گرید
کارت‌ها) و قابل‌استفادهٔ مجدد به‌عنوان سکشن ویژه در صفحهٔ اصلی. کانسپت: پوستر تایپوگرافیک
بدون تصویر؛ نام مقصد (`shortTitle`) با پینار درشت جای عکس می‌نشیند. کارت `TourCard.tsx`
سالم است و دستکاری نمی‌شود.

نزدیک‌ترین آیتم‌های رجیستری وایب‌فارسی: `card` (کادر محتوا، `components/ui/card.tsx`)،
`button` (واریانت‌های `brand` و `secondary`)، `badge` (واریانت `brand`)، `separator`، `price`.
آیتم مستقلی برای «بنر تبلیغاتی تور» در رجیستری نیست؛ پنل تایپوگرافیک از ترکیب همین
آیتم‌ها ساخته می‌شود، نه استایل من‌درآوردی.

## ۲. ساختار کامپوننت (کپی‌دقیق)

فایل پیشنهادی: `site/components/site/TourBanner.tsx` — پراپ `{ tour: Tour }` از
`@/lib/tours`. انتخاب این‌که «تور تازه» کدام است با dev/صفحه است (پیشنهاد: `TOURS[0]`)؛
هیچ فیلد تازه‌ای در داده لازم نیست.

```tsx
import { ArrowLeft, CalendarDays, MapPin, Phone } from "lucide-react";
import Link from "next/link";
import { Badge } from "@/components/ui/badge";
import { Button } from "@/components/ui/button";
import { Card } from "@/components/ui/card";
import { Price } from "@/components/ui/price";
import { fa } from "@/lib/utils";
import { PHONE_MOBILE_LINK } from "@/lib/site";
import type { Tour } from "@/lib/tours";

/**
 * بنر «تور تازه» برای بالای /tours (قابل استفاده در خانه).
 * پوستر تایپوگرافیک: نام مقصد جای عکس. هیچ تصویری ندارد.
 */
export function TourBanner({ tour }: { tour: Tour }) {
  const titleId = `tour-banner-${tour.slug}`;
  return (
    <Card
      aria-labelledby={titleId}
      className="grid gap-6 p-6 sm:p-8 md:grid-cols-[1fr_18rem]"
    >
      {/* ستون متن: در موبایل زیر پنل، در دسکتاپ راست (ابتدای خواندن) */}
      <div className="order-2 flex flex-col gap-6 md:order-1">
        <div className="space-y-4">
          <Badge variant="brand">تور تازه</Badge>
          <h2
            id={titleId}
            className="font-display text-3xl font-bold leading-snug sm:text-4xl"
          >
            {tour.title}
          </h2>
          <p className="max-w-2xl text-base leading-8">{tour.summary}</p>
        </div>

        <dl className="flex flex-wrap items-center gap-x-6 gap-y-3 text-sm text-muted-foreground">
          <div className="flex items-center gap-2">
            <CalendarDays aria-hidden className="size-4" />
            <dt>مدت:</dt>
            <dd>
              {fa(tour.days)} روز و {fa(tour.nights)} شب
            </dd>
          </div>
          <div className="flex items-center gap-2">
            <MapPin aria-hidden className="size-4" />
            <dt>مسیر:</dt>
            <dd>{tour.route}</dd>
          </div>
          <div className="flex items-center gap-2">
            <dt>شروع قیمت از</dt>
            <Price amount={tour.priceFrom} size="md" />
          </div>
        </dl>

        <div className="flex flex-wrap items-center gap-3">
          <Button asChild variant="brand" size="lg">
            <a href={PHONE_MOBILE_LINK}>
              <Phone aria-hidden />
              تماس با کارشناس
            </a>
          </Button>
          <Button asChild variant="secondary" size="lg">
            <Link href={`/tours/${tour.slug}`}>
              مشاهدهٔ جزئیات تور
              <ArrowLeft aria-hidden />
            </Link>
          </Button>
        </div>
      </div>

      {/* پنل تایپوگرافیک مقصد: در موبایل بالا، در دسکتاپ ستون چپ (پایان خواندن) */}
      <div className="order-1 flex flex-col justify-center border-b border-border pb-6 md:order-2 md:border-b-0 md:border-s md:pb-0 md:ps-8">
        <span aria-hidden className="block h-px w-16 bg-border" />

          <span aria-hidden className="block size-2.5 shrink-0 rounded-full bg-brand" />
        </p>
      </div>
    </Card>
  );

```

## ۳. کلاس‌ها و توکن‌های دقیق

| المان | کلاس/توکن | توضیح |
|---|---|---|
| بدنهٔ بنر | کامپوننت `Card` سایت (خودش `rounded-surface border-line border-border bg-card text-card-foreground shadow-surface`) | صفر کلاس دستی برای کادر؛ ۲۲ پیکسل از توکن `--shape-surface` می‌آید |
| پدینگ | `p-6 sm:p-8` | طبق بریف |
| چیدمان | `grid gap-6 md:grid-cols-[1fr_18rem]`؛ ستون متن `order-2 md:order-1`؛ پنل `order-1 md:order-2` | موبایل: پنل بالا؛ دسکتاپ: پنل چپ (پایان خواندن راست‌به‌چپ) |
| بج | `Badge variant="brand"` → `rounded-full bg-brand/15 text-brand-foreground` | فیل کوچک کهربایی؛ متن تنها روی روشن ندارد |
| تیتر | `font-display text-3xl font-bold sm:text-4xl`، تگ `h2` با `id` و `aria-labelledby` | وزن محاسباتی ۷۰۰ (انحراف ۱ را ببین) |
| خلاصه | `text-base leading-8` با رنگ پیش‌فرض متن (نه muted) | طبق حکم ۲ آرت‌دایرکشن |
| ردیف داده‌ها | `dl` با آیتم‌های `text-sm text-muted-foreground`؛ آیکون‌های `size-4` از lucide | مدت/مسیر/قیمت؛ ارقام با `fa()`، قیمت با کامپوننت `Price` |
| CTA اصلی | `Button variant="brand" size="lg"` → `bg-brand text-brand-foreground ... shadow-control` | لینک `PHONE_MOBILE_LINK` از `@/lib/site` |
| CTA ثانویه | `Button variant="secondary" size="lg"` به `/tours/{slug}` | آیکون `ArrowLeft` (جهت جلو در راست‌چین) |
| پنل مقصد | `font-display text-5xl sm:text-6xl`، تراز `justify-end` (سمت پایان)؛ خط مویی `h-px w-16 bg-border` بالا؛ نقطهٔ `size-2.5 rounded-full bg-brand` | امضای بصری کهربایی کوچک |
| جداکنندهٔ داخلی | `md:border-s md:border-border md:ps-8` روی پنل؛ `border-b border-border pb-6` در موبایل | تکمیل جزئی طرح (انحراف ۳) |
| حرکت | هیچ هاور/انیمیشن ورودی؛ فقط رفتار پیش‌فرض دکمه‌ها (`active:[transform:var(--press)]` از واریانت) | سقف تم: `duration-(--motion)` یعنی ۲۰۰ میلی‌ثانیه |

صفر رنگ هگز خام؛ صفر عدد جادویی؛ همه از توکن تم graphite-soft.

## ۴. متن‌های فارسی (طبق persian-ui-copy)

رجیستر سراسری محصول: رسمیِ انسانی با «شما» (نه محاوره، نه اداری). همهٔ رشته‌ها:

- بج: «تور تازه»
- لیبل‌های داده: «مدت:»، «مسیر:»، «شروع قیمت از»
- مقدار مدت: «{عدد فارسی} روز و {عدد فارسی} شب» (مثلاً «۷ روز و ۶ شب»)
- CTA اصلی: «تماس با کارشناس»
- CTA ثانویه: «مشاهدهٔ جزئیات تور»

نکته‌ها: ارقام همه‌جا فارسی (`fa()` و `Price` با جداکنندهٔ «٬»)؛ نیم‌فاصله در «می‌شود/مشاهدهٔ»
رعایت شده؛ «شروع قیمت از» و «تماس» با همان واژه‌های `TourCard` و `CallButtons` یکدست است؛
تیتر و خلاصه مستقیم از دادهٔ تور می‌آیند (تک‌منبع).

## ۵. رفتار ریسپانسیو

- موبایل (`<md`): ستون تکی؛ پنل تایپوگرافیک بالا (نام مقصد)، سپس بج ← تیتر ← خلاصه ←
  داده‌ها ← CTAها. خواندن راست‌به‌چپ نمی‌شکند. دکمه‌ها `flex-wrap` می‌پیچند.
- دسکتاپ (`md+`): دو ستون؛ راست: ستون متن؛ چپ: پنل نام مقصد با عرض ثابت ۱۸rem
  (۲۸۸ پیکسل) و جداکنندهٔ خط مویی.
- نام‌های بلند (مثل «بانکوک و پاتایا») در `text-6xl` ممکن است دو خط شود؛ اشکالی ندارد،
  تراز پایان (`justify-end`) حفظ می‌شود.

## ۶. جای قرارگیری در صفحه

در `app/tours/page.tsx`، بین هدر و گرید کارت‌ها:

```tsx
<section className="mt-10">
  <TourBanner tour={TOURS[0]} />
</section>
```

گرید فعلی با `mt-10` سر جایش می‌ماند (ریتم صفحه حفظ می‌شود). در صفحهٔ اصلی هم به‌عنوان
سکشن داخل کانتینر `max-w-6xl` با همان فاصلهٔ سکشن‌ها قابل استفاده است.

## ۷. انحراف از بریف (با دلیل)

۱. **وزن تیتر از توکن نیست.** بریف گفته «وزن از توکن `--type-display-weight`»؛ ولی سیم‌کشی
   سایت (حکم آرت‌دایرکشن ساعت ۰۵) این توکن را فقط روی `h1` قاعدهٔ سراسری گذاشته چون
   `.font-display` یوتیلیتیِ هم‌نام با خانوادهٔ فونت است و متداخل می‌شود. تیتر بنر `h2`
   است (صفحهٔ `/tours` خودش `h1` دارد)، پس از `font-bold` استفاده شد؛ وزن محاسباتی همان
   ۷۰۰ است، فقط منبع یوتیلیتی است نه توکن. گسترش قاعده به `h2` حکم آرت‌دایرکشن می‌خواهد.
۲. **بج `brand` فیل کم‌رنگ است نه سالید.** واریانت `brand` بج در رجیستری و سایت
   (`bg-brand/15`) فیل ۱۵ درصدی می‌سازد؛ این با قانون مصرف برند («فقط فیل‌های کوچک»)
   و با بج `TourCard` یکدست است، پس همان نگه داشته شد.
۳. **جداکنندهٔ داخلی بین ستون‌ها.** بریف فقط خط مویی بالای نام و نقطهٔ کهربایی را گفته؛
   برای جدایی پنل از ستون متن در دسکتاپ یک `border-s` خط مویی افزوده شد؛ در زبان
   «ریتم خط مویی» تم و هم‌خانواده با `Separator` کارت‌هاست. تکمیل جزئی، نه تغییر مفهوم.

## ۸. معیار پذیرش برای qa

۱. بدون هیچ تصویری، بنر «تمام‌شده» به نظر می‌رسد؛ هیچ حس «به‌زودی عکس می‌آید» نیست.
۲. همهٔ ارقام فارسی‌اند (`fa()` و `Price`)؛ جداکنندهٔ هزارگان «٬».
۳. راست‌چین درست: دسکتاپ پنل چپ، موبایل پنل بالا؛ نام مقصد تراز به سمت پایان.
۴. کنتراست کامل روی تم روشن؛ `grep` صفر مورد `text-brand` تنها.
۵. هر دو CTA با Tab فوکس‌پذیر و فوکس‌رینگ از توکن دکمه.
۶. `prefers-reduced-motion`: بدون انیمیشن ورودی؛ فقط فشردن دکمه.
۷. صفر هگز خام؛ گوشه‌ها فقط `rounded-surface` و `rounded-full`؛ خطوط فقط `border-border`.
۸. کپی‌ها دقیقاً: «تور تازه»، «تماس با کارشناس»، «مشاهدهٔ جزئیات تور».
۹. موبایل: CTAها می‌پیچند و خوانا می‌مانند؛ نام مقصد بلند نمی‌شکند.
۱۰. ممیزی وایب‌فارسی و فارسی‌یوآی روی آیتم‌های `card`/`button`/`badge`/`price` سبز.
