## قلم الف — وزن واحد ۷۰۰ برای h1ها + سیم‌کشی توکن `--type-display-weight`

### انتخاب مکانیزم

قاعدهٔ سراسری `h1` در `globals.css` که از توکن می‌خواند، به‌علاوهٔ حذف کلاس‌های وزن از هر ۸ h1.
چرا نه یوتیلیتی تیلویند: در تیلویند ۴، کلید `--font-weight-display` یوتیلیتی `font-display`
می‌سازد که با یوتیلیتی خانوادهٔ فونتِ `--font-display` هم‌نام و متداخل است؛ سیم‌کشی از مسیر
cascade بی‌ابهام و تک‌منبع است.

نکتهٔ لایه‌بندی: قاعدهٔ `h1` بیرون از `@layer` نوشته می‌شود، پس بر یوتیلیتی‌های وزن (لایهٔ
`utilities` تیلویند) غلبه می‌کند؛ این عمدی است و «وزن واحد» را تضمین می‌کند. اگر روزی h1ای
وزن متفاوت خواست، همان‌جا در CSS بازنویسی شود، نه با کلاس.

### دیف ۱ — سیم‌کشی توکن در `site/app/globals.css` (بعد از خط ۱۲۸)

قبل:
```
h1,
h2,
h3,
.font-display {
  font-family: var(--font-display);
  line-height: 1.35;
  letter-spacing: 0;
}
```

بعد (همان بلوک + قاعدهٔ تازه):
```
h1,
h2,
h3,
.font-display {
  font-family: var(--font-display);
  line-height: 1.35;
  letter-spacing: 0;
}

/* وزن واحد دیسپلی از توکن می‌آید؛ حکم آرت‌دایرکشن ۱۹ مهر ۱۴۰۵.
   بیرون از لایه است تا بر یوتیلیتی‌های وزن غلبه کند و «وزن واحد» تضمین شود. */
h1 {
  font-weight: var(--type-display-weight);
}
```

## قلم ب — برگرداندن h2 بلاک FAQ به مقیاس سکشن

`site/components/blocks/faq.tsx` خط ۹ —
قبل: `<h2 className="text-3xl font-bold">{title}</h2>`
بعد: `<h2 className="text-2xl font-bold sm:text-3xl">{title}</h2>`

چرا همین: مقیاس سکشن خود سایت (`app/page.tsx:110`) دقیقاً `text-2xl font-bold sm:text-3xl`
است؛ `font-bold` می‌ماند چون حکم فقط اندازه را برگرداند. بلاک در `tours/[slug]` و
`guide/[slug]` رندر می‌شود (هر دو زنده‌اند). `contact.tsx:36` و `cta.tsx:11` حکمی ندارند چون
گرپ تأیید کرد هیچ صفحه‌ای `ContactBlock` و `CtaBlock` را ایمپورت نمی‌کند (کامپوننت مرده).

## قلم ج — تعویض فونت مونوی عدد ۴۰۴ با فونت دیسپلی

`site/app/not-found.tsx` خط ۱۵ —
قبل: `<p className="font-mono text-7xl font-bold tabular-nums text-foreground/15 sm:text-8xl">۴۰۴</p>`
بعد: `<p className="font-display text-7xl font-bold tabular-nums text-foreground/15 sm:text-8xl">۴۰۴</p>`

یوتیلیتی `font-display` از `--font-display` (پینار) در `@theme inline` موجود است؛ `font-bold`
و `tabular-nums` و رنگ تزئینی سر جایش می‌ماند.

## معیار پذیرش برای qa (پس از اعمال هر سه قلم)

۱. گرپ `font-extrabold` در `app` و `components` صفر شود و هیچ h1ای کلاس وزن نداشته باشد.
۲. وزن محاسبه‌شدهٔ هر ۸ h1 در بازرس مرورگر ۷۰۰ باشد.
۳. تغییر موقت `--type-display-weight` در `:root` وزن همهٔ h1ها را عوض کند (اثبات سیم‌کشی توکن).
۴. h2 بلاک FAQ در موبایل ۲۴ پیکسل و از `sm` به بعد ۳۰ پیکسل باشد (تطبیق با `page.tsx:110`).
۵. عدد ۴۰۴ با پینار رندر شود (نه فونت سیستمی) و بافت تزئینی کم‌رنگ مثل قبل بماند.
۶. بیلد سبز.
