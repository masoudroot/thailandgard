# قلم‌های پارک‌شدهٔ تیم تحلیل

خانهٔ قلم‌های انتظار رویداد (قانون ۴ پروتکل سفت نوبت). هر قلم یک سطر: نام، مالک، «شرط بیدارشدن».
در گزارش هر نوبت فقط یک خط می‌آید: «پارک‌شده‌ها: N قلم؛ شرط بیدار شده؟ بله/خیر» — نه بازنویسی همان پاراگراف‌ها.
قلمی که بیدار شد از این فایل حذف می‌شود و به «نیمه‌تمام فعال» برمی‌گردد.

(ساختهٔ جراحی دوم پلی‌بوک، ۱۴۰۵/۰۷/۲۱ ساعت ۰۴:۴۰ — از بخش «چه ماند و چرا»ی گزارش ۰۳ امروز)

| قلم | مالک | شرط بیدارشدن |
|-----|------|---------------|
| ردیف `lead-alert` سرور (F-017) — منتظر رویداد لید واقعی؛ تزریق مصنوعی ممنوع | تیم تحلیل | فیلتر تگ `lead-alert` روی `intel_feed` بیشتر از صفر، یا `leads_stats()` غیرخالی |
| جدول `lead_status_history` (مایگریشن ۰۰۶) | مسعود (SQL Editor) — بلوکر بیرونی | اجرای مایگریشن و تأیید SELECT |
| زیرقلم `tel_fallback_click` بدون منبع سه‌بخشی (هندآف به dev؛ یافتهٔ ۳۴) | dev | پاسخ یا اقدام تازهٔ dev |
| یافتهٔ ۴۴ (کلیک‌های نیمه‌شب تماس؛ برچسب «حدس») | lead / design | مخرج (راستی‌آزمایی دیتاگرفتن کلریتی) یا بُعد (انتساب کلیک‌ها به صفحه و کانال) |
