# بایگانی محتوای منتشرشده

هر درفتی که وضعیتش به `منتشرشده` رسید، فایلش از `DRAFTS/` به این‌جا می‌آید.

## قرارداد بایگانی

- نام فایل هنگام انتقال عوض نمی‌شود: `YYYY-MM-DD-slug.md`.
- سربرگ فایل با `state: منتشرشده` و `published: YYYY-MM-DD` به‌روز می‌شود.
- اگر یک متن بعداً با خبر تازه به‌روز شد، نسخهٔ تازه همان فایل را دارد؛ نسخهٔ قبلی در ته فایل با سربرگ `## نسخهٔ قبلی (YYYY-MM-DD)` نگه داشته می‌شود تا تاریخچه گم نشود.
- فقط یافته و لینک منابع؛ کپی متن کامل منابع بیرونی ممنوع.
