# بایگانی محتوای منتشرشده

هر درفتی که منتشر شد، فایلش از `DRAFTS/` به این‌جا می‌آید.

## قرارداد بایگانی

- نام فایل هنگام انتقال عوض نمی‌شود: `YYYY-MM-DD-slug.md`.
- سربرگ فایل همان سربرگ استاندارد است (`عنوان / وضعیت / تاریخ / نویسنده / منبع خوراک اطلاعات`)؛ `وضعیت` به `نهایی` می‌رسد و سطر `تاریخ انتشار: ...` به آن اضافه می‌شود.
- اگر یک متن در ادامه با خبر تازه به‌روز شد، نسخهٔ تازه همان فایل را دارد؛ نسخهٔ قبلی در ته فایل با سربرگ `## نسخهٔ قبلی (تاریخ)` نگه داشته می‌شود تا تاریخچه گم نشود.
- فقط یافته و لینک منابع؛ کپی متن کامل منابع بیرونی ممنوع.
- فهرست بایگانی در `../INDEX.md` است؛ با هر انتقال همان‌جا ثبت می‌شود.
