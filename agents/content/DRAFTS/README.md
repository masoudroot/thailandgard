# پوشهٔ درفت‌ها

هر متن پیش از انتشار این‌جا زندگی می‌کند. قانون پایپلاین: درفت نیمه‌تمام تا تحویل به مدیر یا انتشار ادامه پیدا می‌کند و هر ساعت اول همان جلو برده می‌شود.

## وضعیت‌ها (در سربرگ هر درفت ثبت می‌شود)

- `برنامه‌ریزی‌شده`؛ از دایجست تیم اطلاعات آمده، هنوز شروع نشده
- `درفت`؛ نسخهٔ اول نوشته شده
- `ویراست`؛ ویراست نهایی خورده و آمادهٔ تحویل است
- `تحویل‌شده`؛ به مدیر تحویل داده شده
- `منتشرشده`؛ روی سایت رفت؛ فایل به `ARCHIVE/` منتقل می‌شود

## نام‌گذاری

`YYYY-MM-DD-slug.md`؛ اسلاگ انگلیسی کوتاه، موضوع فارسی در سربرگ.

## سربرگ هر درفت

```
---
title: عنوان فارسی
state: برنامه‌ریزی‌شده
source: لینک منبع اصلی از دایجست
angle: زاویهٔ پیشنهادی بلاگ
created: 2026-10-10
---
```
