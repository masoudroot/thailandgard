# آمادگی فیکس og:title | اجرای دوم ساعت ۰۲ | ۱۹ مهر ۱۴۰۵ (برای اعمال در ساعت ۰۳)

## راستی‌آزمایی وضعیت فعلی (تأیید یافتهٔ seocontent)

- فقط `site/app/layout.tsx` (خط ۵۲) بلاک `openGraph` دارد: `title: «تایلندگرد؛ متخصص تور تایلند»` و `description: SITE_TAGLINE` («فقط تور تایلند، با مشاورهٔ تلفنی کارشناسان مقصد»).
- هیچ صفحه‌ای `openGraph.title` یا `openGraph.description` جدا ندارد (grep روی کل `site/app`).
- رفتار مرج متادیتای Next: `openGraph` در سگمنت‌ها فیلدبه‌فیلد مرج می‌شود؛ `title` سطح صفحه به `openGraph.title` سرریز نمی‌شود وقتی لی‌اوت آن را صریح ست کرده. پس **همهٔ** اشتراک‌گذاری‌ها (تلگرام/واتس‌اپ) الان عنوان کلی لی‌اوت را نشان می‌دهند — یافته درست است.
- صفحه‌هایی که `title`/`description` خودشان را دارند: خانه (`app/page.tsx` خط ۳۱، `title.absolute`)، `tours/[slug]` و `guide/[slug]` (هر دو `generateMetadata`).
- صفحه‌های بدون هیچ متادیتا: `tours/page.tsx` و `contact/page.tsx` (عنوان پیش‌فرض لی‌اوت + تمپلیت `%s؛ تایلندگرد`).

## الگوی پیاده‌سازی پیشنهادی (ساعت ۰۳)

در متادیتای هر صفحه، `openGraph: { title, description }` صریح بگذار (روی `openGraph.title` لی‌اوت می‌نشیند؛ تمپلیت `title` روی `openGraph.title` اثر ندارد پس پسوند «؛ تایلندگرد» دو بار نمی‌آید):

- `app/page.tsx` (استاتیک): `openGraph: { title: «تور تایلند؛ سفر تخصصی با مشاور تلفنی؛ تایلندگرد», description: <همان description صفحه> }`
- `app/tours/page.tsx` (متادیتای تازه لازم دارد): `title: «تورهای تایلند»` + `openGraph.title: «تورهای تایلند؛ پوکت، بانکوک، سامویی، کرابی؛ تایلندگرد»`
- `app/tours/[slug]/page.tsx` (در `generateMetadata`): `openGraph: { title: \`${tour.title}؛ تایلندگرد\`, description: tour.summary }`
- `app/guide/[slug]/page.tsx` (در `generateMetadata`): `openGraph: { title: \`${guide.title}؛ تایلندگرد\`, description: guide.excerpt }`
- `app/contact/page.tsx` (متادیتای تازه لازم دارد): `title: «تماس با تایلندگرد»` + `openGraph.title: «تماس با تایلندگرد؛ مشاورهٔ تلفنی تور تایلند»`

## جدول نهایی ۸ عنوان (حل‌شده با عنوان‌های واقعی کد)

| صفحه | og:title نهایی |
|---|---|
| خانه `/` | تور تایلند؛ سفر تخصصی با مشاور تلفنی؛ تایلندگرد |
| فهرست تورها `/tours` | تورهای تایلند؛ پوکت، بانکوک، سامویی، کرابی؛ تایلندگرد |
| تور پوکت (`phuket-7-days`) | تور پوکت ۷ روزه؛ فی‌فی، جیمز باند و هتل ساحلی؛ تایلندگرد |
| تور بانکوک و پاتایا (`bangkok-pattaya-8-days`) | تور بانکوک و پاتایا ۸ روزه؛ تایلندگرد |
| تور سامویی (`samui-7-days`) | تور سامویی ۷ روزه؛ تایلندگرد |
| تور کرابی (`krabi-6-days`) | تور کرابی ۶ روزه؛ تایلندگرد |
| راهنمای ویزا (`/guide/thailand-visa-guide`) | ویزای تایلند برای ایرانیان؛ مدارک، هزینه و زمان صدور؛ تایلندگرد |
| تماس `/contact` | تماس با تایلندگرد؛ مشاورهٔ تلفنی تور تایلند |

نکته: برای راهنماهای دیگر (`best-time-to-visit-thailand`، `phuket-vs-samui`) الگوی `${guide.title}؛ تایلندگرد` خودکار همان کار را می‌کند؛ جدول بالا فقط نمونهٔ ویزاست.

## راستی‌آزمایی بعد از اعمال (qa)

بیلد سبز + خواندن HTML رندرشدهٔ هر صفحه: تگ‌های `og:title` و `og:description` باید مقدارهای جدول بالا باشند، نه مقدار لی‌اوت. `twitter:title` را هم چشم‌نظری چک کن (از `og:title` ارث می‌برد).
