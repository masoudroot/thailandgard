**راه‌حل دائمی (دفاع در عمق):**

- سقف حافظه ۲ گیگ برای کانتینر n8n (در برابر ۴۰۰ مگ مصرف عادی): نشتی حافظه به‌جای فریز، ری‌استارت تمیز می‌شود.
- مانیتور ۵ دقیقه‌ای خارجی (فاز ۰) همچنان لایهٔ دوم و هشداردهنده است.
- بکاپ کامپوز: `docker-compose.yml.bak-20261012-watchdog`

## فاز ۷: ممیزی ورک‌فلو و بهینه‌سازی (۱۴۰۵/۰۷/۲۰) ✅ انجام شد
**یافته‌های ممیزی:**

- در n8n 2.42 حالت `whenComplete` حذف شده؛ راه درست `responseNode` + گره Respond to Webhook است.
**اصلاحات:**

- سایهٔ قدیمی حذف شد؛ خط لولهٔ قدیمی غیرفعال شد.
- پایپ‌لاین deep حدود ۵.۵ دقیقه طول می‌کشد (۶ فراخوانی LLM ترتیبی)؛ برای HTTP سینک بالای ۶۰ ثانیه باید fast یا آسنک استفاده شود.
