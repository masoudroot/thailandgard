# هندآف تیم وایب‌فارسی به dev | اجرای :۳۵ ساعت ۰۲، ۲۰ مهر ۱۴۰۵

## ۱. یافتهٔ «قاعدهٔ مردهٔ reduced-motion blur-text»؛ راستی‌آزمایی دقیق‌تر و حکم اصلاح‌شده

**وضعیت:** قاعدهٔ خاص در `site/app/globals.css:143` واقعاً مرده است (استایل اینلاین `site/components/animations/blur-text.tsx:8` آن را شکست می‌دهد). ولی حکم :۰۵ من دربارهٔ اثر این مرگ ناقص بود. راستی‌آزمایی دقیق‌تر نشان داد قاعدهٔ فراگیر `site/app/globals.css:183-192` داخل همان مدیاکوئری قرار دارد:

```css
*,
*::before,
*::after {
  animation-duration: 0.01ms !important;
  transition-duration: 0.01ms !important;
}
```

این قاعده روی همان اسپن‌های blur-text هم می‌نشیند و چون `!important` دارد، از استایل اینلاین می‌برد. انیمیشن اینلاین در حالت reduced-motion در ۰٫۰۱ میلی‌ثانیه تمام می‌شود و به فریم پایانی (`opacity: 1`، بدون بلور) می‌رسد؛ یعنی رفتار موردانتظار (متن بلافاصله خوانا، بدون حرکت) محقق است. **پس باگ دسترس‌پذیری زنده نیست و هیچ اقدامی لازم‌الاجرا نیست.**

**اقدام اختیاری (نه لازم‌الاجرا):** اگر سخت‌سازی صریح می‌خواهید، این دیف یک‌خطی در `site/app/globals.css:143`:

```diff
 @media (prefers-reduced-motion: reduce) {
-  .blur-text span { animation: none; opacity: 1; filter: none; transform: none; }
+  .blur-text span { animation: none !important; opacity: 1 !important; filter: none !important; transform: none !important; }
 }
```

فایل آیتم (`blur-text.tsx`) دست‌نخورده می‌ماند؛ diff صفر آیتم حفظ می‌شود.

## ۲. تلهٔ مشابه hero-fade؛ حکم اصلاح‌شده

نگرانی :۰۵ («پیاده‌سازی fade باید فقط کلاس‌محور باشد») با همان قاعدهٔ فراگیر ۱۸۳-۱۹۲ پوشش داده می‌شود؛ هر انیمیشنی، کلاس‌محور یا اینلاین، زیر reduced-motion خنثی می‌شود. پس شرط کلاس‌محور برای hero-fade **اجباری نیست**؛ فقط توصیهٔ تمیزی کد است. سند تطبیق design نیازی به اصلاح ندارد.

## ۳. migration تایم‌لاین؛ مشروط به حکم artdir (فعلاً بدون اقدام)

**وضعیت حکم:** تا این لحظهٔ اجرا artdir حکمی دربارهٔ جهت افقی نداده است (گزارش :۳۵ artdir هنوز نیامده و در گزارش :۰۵ هم نیست). **dev فعلاً اقدام نکند.**

وقتی حکم آمد:

- **اگر artdir به افقی رأی داد:** فایل هدف `site/components/site/OctoberTimeline.tsx` می‌ماند و فقط این idiomها از آیتم `components/timeline` گرفته می‌شود: الگوی `activeIndex` برای وضعیت فعال/سپری‌شده، نقطه‌های `size-2.5` روی ریل، تاریخ دوقلو با `formatJalali` برای هر سه ایستگاه (۱۸ مهر، ۲۳ مهر، ۲۶ مهر؛ معادل‌های میلادی ۱۰/۱۵/۱۸ اکتبر با محاسبه راستی‌آزمایی شود). هر `text-[11px]` آیتم به `text-xs` تبدیل شود (قانون بدون مقدار arbitrary). جهت افقی با ردیف DEVIATIONS ثبت شود.
- **اگر artdir به افقی رأی نداد:** migration کامل به `components/timeline` انجام شود و فایل دست‌ساز حذف گردد.
