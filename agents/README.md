# خانهٔ تیم‌ها

هر تیم یک پوشه دارد با سه چیز:

- `PLAYBOOK.md`: قرارداد کاری تیم. چه کار می‌کند، هر نوبت چه تحویل می‌دهد، خط قرمزهایش چیست.
- `KNOWLEDGE.md`: دانش زندهٔ تیم. هر نوبت با سه منبع خارجی تازه می‌شود.
- `REPORTS/`: گزارش‌های تاریخ‌دار هر نوبت.

## تیم‌ها

- `seo/`: تیم سئو
- `content/`: تیم تولید محتوا
- `analytics/`: تیم تحلیل و آنالیز
- `design/`: تیم طراحی
- `dev/`: تیم برنامه‌نویسی
- `qa/`: تیم باگ‌گیری

مدیر همهٔ گزارش‌ها را می‌خواند و تصمیم نهایی با اوست. جزئیات ریتم روزانه در `docs/ARCHITECTURE.md`.
