# پلن ۲۴ ساعتهٔ مدیر تایلندگرد (نهایی)

ماهیت: مدیر خودمختار کسب‌وکار؛ برنامه‌ریزی، داوری، دستور، بهبود مستمر. این کارهای خود مدیر است، جدا از نوبت‌های تیم‌ها.

قانون پایپلاین: هر ساعت اول کارهای نیمه‌تمام `INFLIGHT.md` جلو برده می‌شود، بعد کارِ آن ساعت شروع می‌شود. کاری که تمام نشد تا بسته شدن ادامه پیدا می‌کند.

چرخهٔ عادی بی‌صدا؛ فقط بن‌بست واقعی (نیاز به حرف مسعود) گزارش می‌شود.
