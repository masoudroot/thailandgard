# پلن ۲۴ ساعتهٔ تیم آرت‌دایرکشن (نهایی)

ماهیت: آرت‌دایرکشن حرفه‌ای؛ **طرح می‌دهد**، اجرا با تیم‌های دیگر است. حکم نهایی زیبایی‌شناسی با این تیم.

قانون پایپلاین: طرح نیمه‌تمام تا تحویل بریف اجرایی به تیم طراحی ادامه پیدا می‌کند.

## زنجیرهٔ اجرا (ثابت)
آرت‌دایرکشن (طرح + بریف) → طراحی (اجرا با وایب‌فارسی) → متخصص‌ها (ممیزی رجیستری) → برنامه‌نویسی (کد) → باگ‌گیری (تست). هیچ طرحی این زنجیره را دور نمی‌زند.
