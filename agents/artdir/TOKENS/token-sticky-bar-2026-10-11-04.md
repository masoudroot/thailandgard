# تصمیم توکن: فضای خالی نوار چسبان موبایل | آرت‌دایرکشن | ساعت ۰۴ | ۱۹ مهر ۱۴۰۵

## مسئله
نوار چسبان موبایل صفحهٔ تور (`site/app/tours/[slug]/page.tsx` خط ۲۷۸: `fixed inset-x-0 bottom-0 ... md:hidden`)
ارتفاع ضمنی دارد (حدود ۹۰ پیکسل در ویوپورت ۳۶۰: سه سطر متن + `py-3` + حاشیه + safe-area).
سکشن پایانی صفحه با عدد جادویی `pb-28 md:pb-16` (خط ۲۵۵) از زیر نوار خالی می‌کند.
اگر محتوای نوار عوض شود (سطر تازه، فونت بزرگ‌تر)، این عدد جادویی بی‌صدا می‌شکند و
فرم تماس زیر نوار می‌ماند؛ هیچ‌کس هم خبر نمی‌شود چون عدد در CSS ثبت نشده.

## تصمیم (حکم نهایی زیبایی‌شناسی)
توکن تازه در `site/app/globals.css`:

```css
:root {
  /* فاصلهٔ خالی زیر سکشن پایانی صفحه‌هایی که نوار چسبان موبایل دارند:
     ارتفاع نوار (~۹۰px) + safe-area ناچ (تا ۳۴px) + تنفس ۱۶px */
  --sticky-bar-clearance: 7.5rem; /* ۱۲۰px */
}

@theme inline {
  --spacing-sticky-bar-clearance: var(--sticky-bar-clearance);
}
```

کلاس مصرف: `pb-sticky-bar-clearance md:pb-16` به‌جای `pb-28 md:pb-16`.

## قانون مصرف (به دیزاین‌سیستم اضافه شد)
- هر صفحه‌ای که نوار چسبان موبایل دارد، فقط همین توکن را روی سکشن پایانی می‌گذارد؛
  عدد جادویی (`pb-24`، `pb-28`، `pb-32`) برای این منظور ممنوع.
- اگر ارتفاع نوار عوض شد، فقط مقدار توکن عوض می‌شود؛ همهٔ صفحه‌ها یک‌جا درست می‌شوند.
- `md:` به بعد همان `pb-16` می‌ماند چون نوار فقط موبایل است.

## چرا ۱۲۰ پیکسل
اندازه‌گیری از روی رندر: `py-3` (۲۴) + سه سطر متن (حدود ۵۶) + `mt-1` (۴) + حاشیهٔ ۱ پیکسلی ≈ ۸۵ تا ۹۰؛
safe-area ناچ‌دار تا ۳۴؛ تنفس ۱۶. جمع سقف ≈ ۱۴۰ ولی نوار `backdrop-blur` و شفاف است و
هم‌پوشانی چند پیکسلی قابل‌قبول؛ ۱۲۰ تعادل بین اطمینان و فضای مرده است.
بازبینی عدد با تیم باگ‌گیری پس از اعمال.

## اثر روی رجیستری وایب‌فارسی
هیچ؛ توکن تازه است، نه استایل من‌درآوردی. در `@theme inline` ثبت می‌شود تا
کلاس تیلویندش (`pb-sticky-bar-clearance`) از همان موتور توکن بیاید.
