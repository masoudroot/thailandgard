# تصمیم توکن: فاصلهٔ خالی نوار چسبان اکتبر | آرت‌دایرکشن | ساعت ۰۴ | ۲۰ مهر ۱۴۰۵

## مسئله

دو نوار چسبان موبایل، دو ارتفاع، یک توکن مشترک (`--sticky-bar-clearance: 7.5rem` = ۱۲۰px):

- نوار تور (`components/site/TourStickyBar`): یک دکمهٔ `h-12` (۴۸px) + `py-3` (۲۴px) + خط بالا (۱px) → حدود ۷۳px + safe-area؛ توکن ۱۲۰px برایش کافی است (حدود ۱۳px تنفس).
- نوار اکتبر (`components/site/MobileOctoberBar`): پس از حکم دو ردیفهٔ M5: `pt-2` (۸) + ردیف قیمت (~۲۸) + `gap-1.5` (۶) + ردیف دکمه‌های `h-10` (۴۰) + `pb-2` (۸) + خط بالا (۱) ≈ ۱۰۶px + safe-area (تا ۳۴px) → نیاز واقعی حدود ۱۴۰px؛ توکن ۱۲۰px در گوشی‌های ناچ‌دار حدود ۲۰px کوتاه می‌آید و چون نوار عملاً مات است (`bg-background/95`)، چند پیکسلِ محتوای پایانی لندینگ زیر نوار می‌ماند.

بزرگ کردن توکن مشترک تا ۱۵۶px مشکل اکتبر را حل می‌کرد ولی روی صفحه‌های تور حدود ۴۰px فضای مردهٔ تازه می‌ساخت؛ خلاف قاعدهٔ تراکم فارسی.

## تصمیم (حکم نهایی زیبایی‌شناسی)

توکن مشترک سر جایش می‌ماند (مال نوار تور است و مقدارش هنوز درست است) و یک توکن تازهٔ مالک‌دار:

```css
:root {
  /* فاصلهٔ خالی زیر سکشن پایانی لندینگ اکتبر (موبایل):
     ارتفاع نوار دو ردیفه (~۱۰۶px) + safe-area ناچ (تا ۳۴px) + تنفس ۱۶px */
  --sticky-bar-october-clearance: 9.75rem; /* ۱۵۶px */
}

@theme inline {
  --spacing-sticky-bar-october-clearance: var(--sticky-bar-october-clearance);
}
```

دیف برای dev روی `site/app/phuket-october/page.tsx` (خط ۱۳۹):

```
- <div className="mx-auto max-w-6xl px-6 pb-sticky-bar-clearance md:pb-16">
+ <div className="mx-auto max-w-6xl px-6 pb-sticky-bar-october-clearance md:pb-16">
```

## قانون مصرف

- هر نوار چسبان توکن فاصلهٔ خالی خودش را دارد؛ توکن مشترکِ «بلندترین نوار» بین نوارهای متفاوت‌ارتفاع ممنوع.
- اگر هندسهٔ نوار اکتبر عوض شد، فقط این توکن عوض می‌شود؛ بودجهٔ ارتفاعش را بریف مالکش می‌نویسد (قاعدهٔ «بودجهٔ ارتفاع نوار چسبان»).
- نوار تازه با ارتفاع تازه = توکن تازه؛ هرگز وراثت از توکن همسایه.

## چرا ۱۵۶ پیکسل

بودجهٔ حکم M5 (اندازه‌گیری qa با متریک واقعی Pinar-FD): ۸ + ~۲۸ + ۶ + ۴۰ + ۸ + ۱ ≈ ۱۰۶؛ safe-area ناچ‌دار تا ۳۴؛ تنفس ۱۶. جمع ۱۵۶.
تحمل هم‌پوشانی چندپیکسلی (در تصمیم قبلی) حذف شد: نوار `bg-background/95` عملاً مات است و آنچه زیرش می‌ماند متنِ واقعی صفحه است، نه پس‌زمینه.

## اثر روی رجیستری وایب‌فارسی

هیچ؛ توکن تازه است، نه استایل من‌درآوردی. در `@theme inline` ثبت می‌شود تا کلاس تیلویندش از همان موتور توکن بیاید.
