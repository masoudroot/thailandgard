# بازبینی کپی — Q3-02

_تاریخ: ۲۸ اکتبر ۲۰۲۶ (۶ آبان ۱۴۰۵). دامنه: ۵۱ URL سایت تولید._

## روش

اسکریپت `site/factory/scripts/copy-audit.ts` هر URL را از `sitemap.xml` می‌خواند، متن دیده‌شده را از HTML جدا می‌کند و قواعد `agents/branding/UX-WRITING.md` را روی آن اجرا می‌کند:

| قاعده | منبع | شدت |
|---|---|---|
| `office_fossil` — «می‌باشد»، «گردید»، «کلیه»، «جهت»، «حاصل فرمایید» | UX-WRITING §ممنوعه‌ها | مسدودکننده |
| `split_verb` — «می شود» با فاصلهٔ ساده به‌جای نیم‌فاصله | UX-WRITING §واژه‌های استاندارد | مسدودکننده |
| `zwnj_mah_asal` — «ماه عسل» به‌جای «ماه‌عسل» | UX-WRITING سطر «ماه‌عسل» | مسدودکننده |
| `long_dash` — خط تیرهٔ بلند (U+2014) و کوتاه (U+2013) | UX-WRITING §ممنوعه‌ها | مسدودکننده |
| `sentence_length` — جملهٔ پاراگراف معرفی بیش از ۲۵ واژه | PLAN Q3-02 | مسدودکننده |
| `unsupported_claim` — «بهترین»، «اولین»، «بزرگ‌ترین»، … | UX-WRITING §ممنوعه‌ها | مشورتی |

قاعدهٔ ادعاها عمداً «مشورتی» است: regex نمی‌تواند «بهترین زمان سفر» (موضوع راهنما) را از ادعای بی‌سند جدا کند. فقط قواعد مکانیکی اجرا را متوقف می‌کنند.

اجرا:

```
npm run factory:copy-audit -- --limit 60 --concurrency 5
```
