## چه چیزی این عددها می‌گویند

1. **پارسال‌نما، امسال‌نما:** هفتهٔ قبل ۶ کلیک تماس ثبت شده و این هفته صفر. برای قضاوت زود است (۷ روز نمونهٔ کوچکی است) ولی روند نزولی است و باید هفتهٔ بعد دوباره دیده شود.
2. **K3 صفر است، نه «کم»:** در کل ۱۴ روز گذشته هیچ لیدی در جدول `leads` نیست. آزمون Q3-04 نشان داد فرم کار می‌کند، پس این صفر یعنی «هیچ‌کس فرم را پر نکرده»، نه «فرم خراب است». تفاوت این دو مهم است.
3. **K2 هنوز اندازه‌گیری نشده:** نرخ تکمیل فرم بدون رویدادهای Clarity قابل محاسبه نیست. تا اتصال توکن API کلریتی، این سنجه در گزارش «اندازه‌گیری نشده» می‌ماند و عدد ساختگی جایش نمی‌گذاریم.

## اجرای هفتگی

گزارش را می‌توان دستی یا از GitHub Actions اجرا کرد:

```bash
cd site
SUPABASE_URL="https://<project-ref>.supabase.co" \
SUPABASE_SERVICE_ROLE_KEY="<service-role-key>" \
npm run factory:lead-weekly -- --out docs/ops/lead-weekly-$(date +%F).md
```

`--now <ISO>` برای بازتولید یک تاریخ گذشته است و `--out` گزارش را در فایل می‌نویسد. کلید سرویس فقط خوانده می‌شود و در خروجی چاپ نمی‌شود.
