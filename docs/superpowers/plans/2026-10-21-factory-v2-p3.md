# Factory v2 - P3 Plan and Execution Record

Date: 2026-10-21

## Scope

- P3-01 SEO Radar from existing GSC, page analytics, and intel feeds.
- P3-02 Tour Fact Contract with source, freshness, and snapshot evidence.
- P3-03 R1 technical SEO gate.
- P3-04 DomainOps SEO workflow.
- P3-05 DomainOps Tour workflow.
- P3-06 Policy-compliant outreach pipeline, dry-run by default.

Production cutover and `FACTORY_RUNTIME=new` remain out of scope.

## Tasks

1. Add a local env loader and PostgREST reader so P3 scripts and activities can use real Supabase credentials without adding a client dependency.
2. Define `TourFact`, price freshness states, snapshot persistence, and the `tour_facts` gate.
3. Define SEO signals, stable dedupe keys, persistence, and plan generation.
4. Add the `seo_r1` technical gate and require it for R1+ policy decisions.
5. Add outreach prospects, suppressions, three-step sequences, schedule columns, and a guarded sender.
6. Add Temporal activities and workflows for SEO Ops, Tour Ops, and Outreach.
7. Add CLI scripts, migrations, tests, README, and credential documentation.
